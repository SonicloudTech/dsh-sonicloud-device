# DeepSeek Harness 智能鼠标插件规格

## 1. 范围

目标宿主：DeepSeek Harness `0.2.1-rc.5`。包名与插件 ID：`dsh-sonicloud-device`，当前实现版本：`0.2.1`。

本期接入通过 BLE 或 2.4G USB 接收器连接的智能鼠标，提供多设备设置、语音打字、翻译、搜索、DPI 与按键配置。设备模型预留其他类型的扩展能力。

语音仅使用鼠标麦克风；移除输入框长按录音及电脑麦克风采集，保留宿主点击、长按和拖选行为。不包含自动发送、语音播报、音频导入、历史录音和会议管理。

本文定义目标要求；实现状态见第 9 节。设置选项、默认值、语言映射统一维护在[鼠标设置](mouse-settings.md)。

## 2. 设备与配置

- 真实 `sn` 是设备配置、事件和鉴权的身份依据，按字符串保存。同一设备的 BLE/USB 通道共用配置；不同设备即使型号相同也独立管理。
- 每次连接使用独立运行期标识，隔离旧连接的迟到事件。上线、离线、通道、电量及 DPI 状态实时更新；未知数据显示“—”。SDK 的 `usb/ble` 表示传输方式，不是产品类型。
- 未取得真实 SN 时显示“设备身份未确认”，临时连接 ID 不用于持久化配置或鉴权。异常重复身份不得静默合并或覆盖配置。
- 断开后保留偏好，重连或重启后恢复。当前查看的设备仅决定设置编辑对象，不决定语音来源；录音设备掉线或通道切换中断时取消会话。

| 数据 | 保存规则 |
| --- | --- |
| 共享配置 | 服务地址、稳定且不含个人信息的调用用户标识。 |
| 设备偏好 | 按 SN 保存语言、标点、DPI、按键动作、搜索引擎和链接；带配置版本，升级保留已有值。 |
| 运行状态 | 连接、电量、会话、音频、结果及 Token 仅保留在内存。 |

新设备独立建档，不复制其他设备偏好。设备与服务配置分开保存，会话使用开始时的配置快照。

以用户提供的截图为布局基准，复用宿主设置组件、主题和滚动行为。侧栏仅保留“声云设备”入口，不展示 ASR 菜单、服务管理或鉴权配置。

| 区域 | 要求 |
| --- | --- |
| 标题 | “声云设备”；说明为“N 台设备已连接 · 为每台设备设置专属偏好”，按已确认身份的在线设备去重计数。 |
| 设备切换 | 显示图片、名称/颜色，使用左右箭头和位置指示点切换；单台时隐藏切换控件。 |
| 基本信息 | 依次显示 SN、连接方式、电量；连接方式显示“蓝牙”或“USB 接收器”。 |
| 无设备/离线 | 无设备时显示“暂无设备连接”及连接提示；当前设备离线后停止下发指令，允许切换其他在线设备。 |

截图数据不作为真实状态或默认值。不支持的设置禁用并说明原因；DPI、M、语音及 AI 键在标题下方以通用设置的小号灰字说明用途。M 键的搜索引擎仅显示下拉选择框，不显示文字标签；链接输入框右侧提供“确认”按钮，不显示地址标签或行内校验提示。子配置与 M 键之间不加分割线。

### 3.2 设置项

按下表排列，选项及保存值以[鼠标设置](mouse-settings.md)为准。

| 设置项 | 控件 |
| --- | --- |
| 语音打字 | 标点开关、识别语言下拉框。 |
| 语音翻译 | 源语言 → 目标语言下拉框。 |
| DPI 键 | DPI 下拉框。 |
| M 键 | 动作下拉框，按动作显示搜索引擎或 URL。 |
| 语音键 | 语音打字/语音翻译单选。 |
| AI 键 | 动作下拉框；完整动作范围待确认。 |

修改后按顺序自动保存并应用于当前设备，无保存按钮；失败就地提示并回退。底部小号警告色“恢复默认”仅重置当前设备。会话中的设置修改下次生效。

DPI 保存值须映射为固件档位；首次保存前不下发默认 DPI，重连恢复已保存偏好。区分保存、下发和硬件确认，失败显示未应用并允许重试，不伪造生效状态。

### 3.3 M 键动作

动作值、菜单顺序和搜索引擎列表统一见[鼠标设置](mouse-settings.md#m-键设置)。

| 动作 | 行为 |
| --- | --- |
| 回车 / 后退 | 分别执行 Enter、Backspace。 |
| 语音打字 | 使用该设备识别语言和标点配置，回填最终文本。 |
| 语音翻译 | 按源语言识别，再翻译为目标语言并回填。 |
| 语音搜索 | 按语音打字配置识别，将完整最终文本经 URL 查询参数编码后追加到所选搜索引擎前缀，打开一次。 |
| 一键链接 | 打开已配置的 HTTP/HTTPS 地址，不采集音频。 |

搜索和链接不依赖输入框、不回填文本。链接仅在点击“确认”时去除首尾空白、校验网址（HTTP/HTTPS 协议可省略，保存和打开均不补写协议），保存成功后 toast 提示并用于后续按键；缺失、无效或保存失败时 toast 报错，当前修改不生效。搜索仅在识别成功且文本非空时执行；浏览器打开失败时提示，不重复打开或换用其他地址。

## 4. 语音会话与输出

### 4.1 调度与流程

语音键和 M 键共用单会话调度，覆盖连接、录音、识别、翻译或搜索全过程。

- 开始时固定来源 SN、连接、触发键、动作、配置和输出目标，并锁定 SDK 音频源；只接收该来源音频，空闲音频不上传。
- 忙碌时其他设备触发提示“其他设备正在使用语音，请稍后重试”，不抢占、不排队；当前设备重复触发不新建会话。
- 仅所属设备及触发键的结束事件可以结束录音；页面切换、其他设备事件和设置修改不影响当前会话。一次物理操作只执行一次动作。

| 阶段 | 行为 |
| --- | --- |
| 开始 | 语音键按下开始、抬起结束；M 键语音动作按 SDK `down` 开始、`up` 结束。打字/翻译先捕获对话、输入框、内容及光标/选区，无目标时提示并停止。 |
| 预览 | 绿色呼吸圆点加单行实时文字；超长跟随末尾、左侧省略。连接阶段不另显“正在连接 ASR”。翻译预览源语言文本。 |
| 松开 | 收完本次尾部音频，发完缓存后发送 `end`，显示“正在整理”。 |
| 完成 | ASR 流结束后合并最终文本：打字回填，翻译显示“正在翻译”并请求译文，搜索打开浏览器。 |
| 取消 | 点击取消、Esc、失焦、来源设备掉线、通道中断或插件禁用时取消；打字/翻译还在切换对话或输入框销毁时取消。提示条立即消失。 |

所有结束路径释放连接、缓存和音频源锁定；取消同时中止刷新与重试，迟到事件不得产生输出或恢复会话。

### 4.2 输出与异常

- 回填前核对原对话、输入框及内容；一致则在原光标处插入或替换选区，不改其余内容、不自动发送。目标变化时保留结果供复制。
- 打字仅回填识别文本，翻译仅回填有效译文；每个会话最多输出一次。成功后隐藏提示条，异常结果保留供复制。
- 空识别提示“未识别到语音”。识别失败、音频丢失、断线或超时不输出不完整结果，也不进入后续翻译/搜索；翻译失败保留识别原文，不冒充译文。不得自动切换设备或服务。

### 4.3 时限

| 阶段 | 上限 |
| --- | --- |
| 单次录音 | 10 分钟。 |
| ASR 就绪等待 | 获取 Token、连接及鉴权重试合计 10 秒，最多缓存对应时长音频；重试不重置上限。 |
| 松开至上传结束 | 15 秒。 |
| `end` 后等待最终结果 | 宿主 5 秒；前端收到上传结束通知后 6 秒兜底。 |
| 文本翻译 | 每次请求默认 15 秒，可配置，独立于 ASR 收尾计时。 |

## 5. 接口与鉴权

依据：用户提供的设备接入 OpenAPI 文档（2.1.0）、[实时识别](https://open.sinicloud.com/documents/webapi/stream-asr)、[文本翻译](https://open.sinicloud.com/documents/webapi/translate-text)及[公共参数](https://open.sinicloud.com/documents/publicparam)。

### 5.1 获取 Token

`POST https://dsh_device.sonicrhino.cc/api/open.sign/generate`

使用 JSON 请求体 `{ "sn": "<来源设备真实SN>" }`，无需登录，仅传 `sn`；签名由服务端完成。

- 仅在 HTTP 成功、`code=0`、`data.token` 非空且 `data.expire_time` 有效并未到期时接受响应。过期时间为秒级 Unix 时间戳，以返回值为准。
- 身份缺失或未确认时停止请求并 toast 提示；HTTP、业务码或响应校验失败均不得继续调用业务接口。
- Token 按“设备接入服务基地址 + SN”仅缓存在宿主内存；同设备 ASR/翻译复用，不跨设备使用。无缓存或已到期时先获取，同键并发刷新合并，旧响应不得覆盖新 Token；禁用、卸载或退出时清空。

ASR 和翻译请求均通过 Header 传 `X-SC-Authorization: <token>`、`X-SC-User-Id: <稳定调用用户标识>`；Token 不加 `Bearer` 前缀、不放入 URL。JSON 请求使用 `Content-Type: application/json; charset=utf-8`。

### 5.2 实时识别

`wss://openapi.sinicloud.com/talentStreamAsr`

| 项目 | 约定 |
| --- | --- |
| Query | 语言映射后的 `lanid`、`lid=0`、`role=0`；不传 `fromlan/tolan`。 |
| 音频 | 无头、小端、16 kHz、16 bit、单声道 PCM；收到 `errCode=1000` 后发二进制帧，每 100 ms 约 3200 字节，每包大于 80 字节，短尾包补静音。 |
| 结果 | `errCode=0` 中 `End=0` 为临时句，`End>0` 为最终句；`3` 仅作预览；`10` 表示流结束，可携带末句。时间字段兼容数字字符串，最终句按 `Begin` 排序、按时间区间去重。 |
| 收尾 | 音频发完 → 文本帧 `end` → 收到 `10` → 合并结果并主动关闭连接；不等待服务端关闭，不将单句完成当作流结束。 |
| 错误 | `1001` 低余额提醒不终止录音；`4010` 按第 5.4 节恢复；额度、并发、License 等错误直接提示。 |

### 5.3 文本翻译

`POST https://openapi.sinicloud.com/v1/translate/text`

| JSON 字段 | 约定 |
| --- | --- |
| `text` | ASR 完整最终文本，非空、最多 5000 字符。 |
| `from` / `to` | 会话源/目标语言经映射后的代码，显式传入且不同；中文 `cn → zh`，完整映射见[鼠标设置](mouse-settings.md)。 |

ASR 成功后请求一次，不翻译临时句。仅 HTTP 成功、`code=0` 且 `data.resultText` 为非空字符串时回填译文。超长、同源/目标语言、无效响应或请求失败均 toast 提示并保留原文，不截断或拆分文本。鉴权恢复见下一节。

### 5.4 无感重试

1. ASR `errCode=4010` 或翻译 `code=1004` 时，清除对应缓存，以原 SN 获取新 Token 并重试失败操作一次；兼容数字及数字字符串。首次失败不弹 toast、不要求重新按键。
2. ASR、翻译分别最多重试一次；请求前发现缓存到期不计重试。刷新失败或重试后的任何错误均停止，只 toast 一次；非鉴权错误不触发刷新，失效 Token 不复用。
3. ASR 鉴权错误发生于连接建立后、音频发送前。关闭旧连接，保留未发送音频，以原参数重连；收到 `1000` 后按序发送，若已松键则发完后发送 `end`。旧事件和定时器不得终止新连接，等待与缓存上限见第 4.3 节。
4. 翻译重试仅重发原 `{ text, from, to }`，不重新识别。恢复期间仍执行会话取消和输出校验规则。

## 6. SDK 与数据要求

使用 [mouse-sdk](https://github.com/SonicloudTech/mouse-sdk) `0.4.20`，经宿主侧独立进程接入。硬件配置、固件映射及开发操作见[开发说明](../contributing/development.md)。

- 设备适配、注册配置、语音会话和输出分离；所有设备指令显式指定 SN。
- 初始化前注册回调，复制回调数据后异步处理，不阻塞 SDK；禁用或卸载时释放进程、监听和会话。
- 复用宿主设置页、overlay、Remote 和文本插入能力，不改写宿主文件。
- 权限、配对、链路警告、数量限制及队列溢出须明确反馈；实际连接上限通过联调确认。
- 应用凭据仅存服务端；插件源码、产物和本地存储均不内置或保存。升级清理本插件旧凭据、停用手填 SN 和本地签名路径，保留设备偏好及调用用户标识，不影响其他插件。
- 仅使用第 5 节服务，旧服务选择不覆盖新配置。远程连接使用 HTTPS/WSS，本地调试除外；不持久化音频，日志不含音频、识别/翻译正文、应用凭据或 Token。

## 7. 验收

以下为实现后的验收要求，不代表已验证。

| 范围 | 核心场景 |
| --- | --- |
| 页面与配置 | 零/一/多设备；按类型展示设置；至少两台同型号设备偏好独立；保存、恢复默认、重连及重启恢复。 |
| 会话隔离 | A 录音时 B 触发被拒绝；B 松键/离线和页面切换不影响 A；取消后无迟到输出。 |
| 语音与回填 | BLE/USB 音频、尾音、多句合并；空输入、已有文本、选区和目标变化；仅输出一次、不自动发送；输入框长按不采集音频。 |
| 翻译 | 语言映射、成功译文、空译文、超长、同源/目标语言及失败；不误回填原文。 |
| 按键与 DPI | 全部 M 键动作、AI 键、设备定向下发及失败提示；搜索覆盖三个引擎和中文、空格、`&`、`#`；无输入框可搜索/打开链接。 |
| Token | 按 SN 隔离、缓存/过期、并发刷新、无效响应、业务失败；首次失效无感恢复，刷新或重试失败仅 toast 一次。 |
| 异常与迁移 | 断网、超时、掉线、通道中断及禁用释放资源；重试不丢音频、不重复输出；旧凭据清理且 Token 不落盘。 |
| 平台 | 目标宿主、SDK 加载、蓝牙权限、USB、多设备和日志检查。 |

## 8. 待确认与联调

- 硬件：M 键时序、尾帧边界、DPI 固件映射、系统按键效果、设备名称/颜色/图片来源。
